# Art source and Roblox model exports

Keep editable source files such as Blender scenes, textures, and working images under this
directory. Canonical Roblox model exports belong under `art/roblox/` when a Studio-authored
model must be recoverable independently of the place file.

Do not map large authored models into the live Rojo tree as thousands of source instances.
Export only intentional canonical assets, and record the matching Studio path and published
asset IDs in the relevant metadata or documentation.
